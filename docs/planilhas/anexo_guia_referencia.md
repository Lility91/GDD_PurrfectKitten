## 3. Resumo do Turno

No seu turno, escolha **uma** das ações abaixo:

### Pegar uma Carta de Camada

- Pegue gratuitamente uma das **Cartas de Camada** na ponta mais afastada do baralho; ou
- Use **Tokens de Pegada** para alcançar uma carta específica na **Área de Compra**.

### Montar um gato

- Use cartas da sua mão para montar um gato sobre uma **Carta Base**;
- Use, no máximo, uma carta de cada camada;
- Depois de montar o gato, verifique se cumpriu algum **Objetivo Trending**.

## 4. Lembretes Importantes

- Você não pode pegar uma **Carta de Camada** e montar um gato no mesmo turno.
- Cada jogador pode ter no máximo 5 **Cartas de Camada** na mão.
- Se você começar seu turno com 5 **Cartas de Camada**, deve obrigatoriamente montar um gato.
- Um gato montado não pode ser desfeito, alterado ou reorganizado depois.
- Cada jogador monta três gatos durante a partida.
- A **Carta de Objetivo de Conjunto** deve permanecer em segredo até o final da partida.
